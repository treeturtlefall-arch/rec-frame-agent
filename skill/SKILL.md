# rec-frame-agent

画像にカメラのファインダー風フレーム（四隅枠＋電池＋赤丸 REC＋タイムスタンプ）を合成する道具を、AIエージェントから使うための手続き。描画は本家 rec-frame-app のエンジンが行い、このスキルは「頼まれたら迷わず1コマンドで付けて、結果を正しく報告する」ことだけを規定する。

## 道具

- コマンド: `rec-frame-agent`（無い場合は `python -m rec_frame_agent` を試し、それも無ければ未導入として導入手順を案内する）
- 導入: リポジトリを clone し `uv tool install .`（または venv に `pip install .`）→ `bash scripts/install_skill.sh` → `rec-frame-agent doctor` が全項目 OK であること
- プリセット: `favorite`（お気に入り）が既定。実体はリポジトリの `favorites.json` が決める。同梱の既定は白枠／電池3本／REC／タイムスタンプは処理した時刻／座布団10%（白飛び自動防止）

## トリガー

- 「お気に入りのフレームつけて」「いつものフレームで」「RECフレームつけて」「ファインダー枠つけて」
- 「文字が白飛びする」「黒くて見えない」「座布団つけて」「文字を見やすくして」
- 画像を生成・編集した直後に「フレームつけて」とだけ言われた場合も対象

## 手順

1. 対象画像を特定する。どれか分からなければ推測せずに聞く。
2. プリセットの指定が無ければ `favorite` を使う。名前で指定されたらその名前を使う（`rec-frame-agent presets list` で実在を確認できる）。
3. 実行する: `rec-frame-agent apply <画像> --preset <名前> --json`
   - 「タイムスタンプなしで」と言われたら `--timecode none` を足す。
   - 「撮影日時で」と明示されたら `--timecode photo` を足す。それ以外では自動で切り替えない（既定は処理した時刻で統一）。
   - 特定の日時を指定されたら `--at 2026-11-03T14:30` の形で渡す。通常は指定しない。
   - 「白飛び・黒飛びを防いで」「文字をくっきり」「座布団を濃くして」と言われたら `--bg-opacity 0.20`〜`0.30` を足す（標準は 0.10、枠色に応じて白/黒が自動反転）。「座布団なしで」と言われたら `--bg-opacity 0.0` を足す。
4. 結果を読む: JSON の `ok` が true なら、`output` の画像を添付して報告する。タイムスタンプを入れた場合は `timecode.text` の時刻も一言添える。座布団を調整した場合はその旨も添える。
5. 失敗時（`ok` が false）は終了コードに従う:
   - 2（設定エラー）: `presets list` の候補から選び直すか、ユーザーに聞く。推測で別プリセットを使わない
   - 3（入力なし／未対応）: パスを確認する。別ファイルを勝手に代用しない
   - 4（出力あり）: 既定の連番命名に任せる（`-o` を付けなければ自動で連番になる）
   - 5（エンジン失敗）: `rec-frame-agent doctor` の結果と一緒に報告する。再試行は1回まで

## 説明を求められたら（「どんなことができるの？」等）

1. まず `rec-frame-agent capabilities --json` を実行し、その内容に基づいて答える。選択肢を記憶で列挙しない（エンジンの定数から動的に返るので、常に正確）。
2. 伝え方の型: 何をする道具か1行 → 変えられる軸を平たい言葉で（色、フォント、要素の ON/OFF、電池の本数、ドットの形、座布団の濃さ、エフェクト、タイムスタンプの方式）→ **気に入った設定は名前を付けて保存でき、お気に入りにできる** → 「見本を見ながら決める？」とギャラリーへ誘う。
3. 長い列挙で押し切らない。相手が興味を示した軸だけ深掘りする。

## お気に入りを決めて保存するフロー

1. 見本ギャラリー（軸別に1項目だけ変えた実物見本）を見せ、チャットで希望を聞く。希望は機械名で受け取る（例: フォントは `DSEG7 Classic(7セグLED)`、ドットは `glow_red`、色は `cyan`、座布団は `0.15`）。
2. 決まった組み合わせで、実物サイズのプレビューを1枚描いて見せる（`apply --preset favorite --json` ではなく、作成予定の設定を一時プリセット相当で適用する。迷ったら `presets create` を先に行い、その名前で `apply` する）。
3. ユーザーの確認が取れたら保存する: `rec-frame-agent presets create <名前> --base favorite <決まった差分> --favorite --json`。土台は原則として現在のお気に入り（`--base favorite`）を使い、差分だけを渡す。
4. 保存後に試しとしてサンプル画像へ1枚適用し、結果を添付して報告する。名前と中身の要約も添える。
5. 同名プリセットがある場合は上書き可否を必ず聞く（`--overwrite` は確認なしに使わない）。

## 守ること

- 元画像は上書きしない（ツール側でも禁止されているが、 `-o` に入力と同じパスを渡さない）。
- 合成までがこのスキルの領分。画像の送信・投稿・公開は、会話側の承認の仕組みに従う。
- 報告は JSON の `output` を正とする。ファイル名の規則からの推測で報告しない。
